# KPlugin AdMax

KPlugin is a tool that supports using AppLovin MAX Unity with KTool.

## How do I get set up?

 1. Open PacakageManager window
 2. Click button [+]
 3. Select [Add package form git URL...]
 4. paste url: <https://github.com/KemLib/KPluginAdMax.git>
 5. Click button [Add]

If you want to use the latest version, replace the URL. <https://github.com/KemLib/KPluginAdMax.git#develop>

## Features

- **App open ads**
- **Interstitial ads**
- **Rewarded ads**
- **Banner ads**
- **MREC ads**
